# Kitchen Helper widgets

Timer console and command widgets for Brendan's Kitchen Helper (a Claude project). Claude loads `kitchen.js` through jsDelivr:

`https://cdn.jsdelivr.net/gh/GITHUB_USER/kitchen-helper@v1/kitchen.js`

To update: upload a new `kitchen.js`, then publish a new release with a new tag (v2, v3, …) and change the tag in the Kitchen Helper project files. Tags keep old chats working and avoid caching delays.
